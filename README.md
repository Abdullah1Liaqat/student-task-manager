# Student Task Manager

## Project Description
A simple web application that lets students add, view, complete, delete and search their tasks. Built as a pair assignment to demonstrate a real Git and GitHub collaborative workflow.

## Team Members
- Student 1: Abdullah Liaqat - BCSF22M520 - @Abdullah1Liaqat
- Student 2: Muhammad Sajjad - BCSF22M540 - @MuhammadSajjad540

## Features
- Add tasks with a title and description
- Display tasks as cards
- Mark tasks as completed / undo
- Delete tasks
- Search tasks by title or description
- Tasks saved in the browser (localStorage)
- Responsive layout

## Technologies
HTML5, CSS3, JavaScript (vanilla), Git, GitHub

## Git Workflow
Feature branches -> push -> GitHub Issue -> Pull Request -> code review by partner -> merge into main -> tag and release.

## Branches
| Branch | Purpose |
| --- | --- |
| main | Stable code |
| feature/task-form | Task input form and core logic |
| feature/task-style | Styling and responsive layout |
| feature/task-search | Task search (closes its GitHub issue) |
| docs/readme-system, docs/readme-application | README merge conflict demonstration |
| docs/final-readme | Final documentation |

## Git Commands Demonstrated
init, status, add, commit, log, branch, switch, diff, diff --staged, clone, remote, push, fetch, pull, merge, stash, restore, reset, revert, show, blame, tag

## GitHub Features Demonstrated
Public repository, Issues, Pull Requests, code reviews, merges, linked issues (Closes #n), tags, releases, contributor graph

## How to Run
1. Clone the repository: git clone https://github.com/Abdullah1Liaqat/student-task-manager.git
2. Open index.html in any web browser.
